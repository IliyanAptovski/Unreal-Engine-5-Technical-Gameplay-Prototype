# Unreal Engine 5 – Third Person Footstep Dust Demo

This project is a small Unreal Engine 5 third-person prototype created as a portfolio piece for a **Junior Unreal Engine Developer** role.  
It focuses on clean gameplay integration, Blueprint scripting, and a simple but effective Niagara visual effect.

---
## 🎮 Project Overview

The project extends Unreal Engine’s Third Person Template by adding **gameplay-driven visual feedback** in the form of **Niagara footstep dust**.

The goal was to demonstrate:
- Understanding of Unreal Engine fundamentals
- Practical use of Niagara for gameplay effects
- Attention to performance and polish

---
## ✨ Key Features

- **Niagara Footstep Dust Effect**
  - Triggered via **Animation Notifies**
  - Spawns at the character’s foot sockets
  - Lightweight, optimized particle system

- **Third-Person Gameplay Setup**
  - Based on Unreal Engine’s Third Person Template
  - Clean level setup for quick testing and iteration

---

## 🛠 Technologies Used

- Unreal Engine 5
- Blueprints
- Niagara VFX System
- Animation Notifies
- Basic level setup, lighting, and post-processing

---
## 📌 Notes

This project is intentionally small and focused, prioritizing clarity, correctness, and good Unreal Engine practices over complexity.
